# Student Management System

## Project Description
A beginner-friendly Student Management System developed using Python. This project allows users to manage student records through a menu-driven application.

## Features
- Add new student records
- View all student records
- Search students by Student ID
- Update student information
- Delete student records
- Prevent duplicate Student IDs
- Validate user input
- Handle invalid inputs using exception handling

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- Classes and Objects
- Lists
- Functions and Methods
- Exception Handling
- Loops and Conditional Statements

## Concepts Practiced
- Constructors (`__init__`)
- Instance attributes and methods
- `self` keyword
- `try-except`
- List operations (`append`, `extend`, `remove`)
- Input validation
- Searching and updating records

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code or Python IDLE.
3. Run the following command:

```bash
python student_management_system.py
```
